# Fotos zur Galerie hinzufügen

## So geht's (3 einfache Schritte):

### 1. Auf GitHub gehen
- Öffne: https://github.com/DEIN-USERNAME/kinderparadies-hanau
- Klicke auf den Ordner **galerie/**

### 2. Fotos hochladen
- Klicke oben rechts auf **"Add file"** → **"Upload files"**
- Ziehe deine Fotos per Drag & Drop rein (JPG, PNG oder WEBP)
- Unten auf **"Commit changes"** klicken

### 3. Fertig!
- Die Website wird automatisch aktualisiert (dauert ca. 1-2 Minuten)
- Die neuen Fotos erscheinen automatisch in der Galerie

## Hinweise:
- Fotos sollten im Format JPG, PNG oder WEBP sein
- Am besten Querformat (sieht besser aus in der Galerie)
- Keine Leerzeichen im Dateinamen (z.B. "malkurs-1.jpg" statt "malkurs 1.jpg")
